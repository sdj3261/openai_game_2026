# 8초 도둑단

8초 동안 움직인 동선을 분신으로 저장해 경비를 속이는 장난감 잠입 게임입니다. 스테이지를 고르고 `시작!`을 누르면 바로 플레이합니다.

## PC에서 실행

```powershell
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 연결 오류 화면이 남아 있다면 서버 실행 후 새로고침하세요. 기본 서버는 PC 내부에서만 접근할 수 있습니다.

## 휴대폰에서 실행

PC와 휴대폰을 같은 Wi-Fi에 연결한 뒤 실행합니다.

```powershell
npm run start:mobile
```

터미널의 `mobile/LAN URLs` 아래에 표시된 주소를 휴대폰에서 엽니다. Windows 방화벽은 신뢰하는 개인 네트워크에서만 허용하고, 공용 Wi-Fi에서는 사용하지 마세요.

## GitHub Pages에 배포

저장소의 `main` 또는 `master` 브랜치에 push하면 GitHub Actions가 정적 게임을 Pages에 배포합니다. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택하세요. 배포된 HTTPS 주소는 별도 서버 없이 PC와 휴대폰에서 바로 열 수 있습니다.

## 조작

- 방향키 / `WASD`: 이동
- `Z`: 소리 미끼로 경비 유인
- `X`: 현재 동선을 분신으로 저장
- `R`: 현재 루프 다시 시작
- `U`: 마지막 분신 취소
- `Backspace`: 월드 초기화
- `M`: 음소거

휴대폰에서는 왼쪽 가상 스틱으로 이동하고 오른쪽 `Z 미끼`, `X 분신` 버튼을 누릅니다. 다시 시작·취소·맵·소리는 하단 보조 버튼으로 조작합니다.

## 8개 스테이지

`스테이지 1 태엽 박물관`에서 시야 회피를 배우고 장난감 공장·캔디 아케이드·구름 연구실·달빛 역·거울 성·왕실 금고를 지나 `스테이지 8 자정 시계탑`의 딱걸이와 맞섭니다. 보석을 얻고 출구에 도착하면 완료입니다.

분신은 `X`를 누를 때만 저장됩니다. 발각되거나 8초가 끝나면 저장된 분신은 유지되지만 새 분신은 생기지 않습니다. 점수는 레이더 노출·재시도·필수보다 많은 분신·완료 시간으로 계산하며, 스테이지별 기기 랭킹에서 비교합니다.

## 검사

```powershell
npm test
```

`test:input`은 모바일 스틱을, `test:profile`은 프로필과 스테이지 순위를, `test:i18n`은 한국어·영어·일본어 문구를, `smoke`는 0.7.0 정적 에셋·게임 글꼴·스프라이트 QC 결과를 검사합니다.

## 시각 에셋

메뉴의 지금이와 최종 보스는 내장 이미지 생성으로 원본을 만들고 Agent Sprite Forge `generate2dsprite` 프로세서로 마젠타 제거, 프레임 분할, 정렬, GIF 내보내기, QC를 수행했습니다. `assets/sprites`에 원본·투명 시트·개별 프레임·프롬프트·검사 메타데이터가 함께 들어 있습니다. 한글 게임 글꼴은 SIL OFL 1.1의 Galmuri11 Bold이며 라이선스를 `assets/fonts`에 동봉했습니다.
