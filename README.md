# 8초 도둑단

8초 전의 움직임을 아까미로 복제해 경비를 속이는 레트로 아케이드 잠입 게임입니다. `STAGE`를 고르고 `PLAY!`를 누르면 바로 시작합니다.

## PC에서 실행

```powershell
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 연결 오류 화면이 남아 있다면 서버 실행 후 새로고침하세요. 기본 서버는 PC 내부에서만 접근할 수 있습니다.

## 휴대폰에서 실행

PC와 휴대폰을 같은 Wi-Fi에 연결한 뒤 실행합니다.

```powershell
npm run start:mobile
```

터미널의 `mobile/LAN URLs` 아래에 표시된 주소를 휴대폰에서 엽니다. Windows 방화벽은 신뢰하는 개인 네트워크에서만 허용하고, 공용 Wi-Fi에서는 사용하지 마세요.

## GitHub Pages에 배포

저장소의 `main` 또는 `master` 브랜치에 push하면 GitHub Actions가 정적 게임을 Pages에 배포합니다. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택하세요. 배포된 HTTPS 주소는 별도 서버 없이 PC와 휴대폰에서 바로 열 수 있습니다.

## 조작

- 방향키 / `WASD`: 이동
- `Z`: 소음으로 경비 유인
- `X`: 현재 동선을 에코로 저장
- `R`: 현재 루프 다시 시작
- `U`: 마지막 에코 취소
- `Backspace`: 월드 초기화
- `M`: 음소거

휴대폰에서는 왼쪽 가상 스틱으로 이동하고 오른쪽 `Z 소음`, `X 에코` 버튼을 누릅니다. 다시 시작·취소·맵·소리는 하단 보조 버튼으로 조작합니다.

## 8 STAGES

`STAGE 01 태엽 박물관`에서 시야 회피를 배우고 장난감 공장·캔디 아케이드·구름 연구실·달빛 역·거울 성·왕실 금고를 지나 `STAGE 08 자정 시계탑`의 딱걸이와 맞섭니다. 보석을 얻고 `EXIT`에 도착하면 `CLEAR`입니다.

