# 8초 도둑단

> **8초 전의 내가, 지금의 나를 돕는다.**
>
> 8초 동안 움직인 동선을 분신으로 저장하고 과거의 나와 역할을 나눠 보석을 훔치는 1인 협동 타임루프 잠입 퍼즐

**OPENAI GAME 2026 제출작 · v0.8.0**

[게임 바로 플레이](https://sdj3261.github.io/openai_game_2026/) · [3분 데모 영상](https://sdj3261.github.io/openai_game_2026/demo/) · [MP4 바로 보기](https://sdj3261.github.io/openai_game_2026/demo/8-second-crew-demo.mp4)

별도 설치·로그인·승인 없이 PC와 모바일 브라우저에서 바로 플레이할 수 있습니다.

[![8초 도둑단 3분 데모](demo/poster.png)](https://sdj3261.github.io/openai_game_2026/demo/)

## 심사위원용 30초 안내

1. `시작!`을 누릅니다.
2. 방향키·`WASD` 또는 화면 조이스틱으로 이동합니다.
3. 빨간 레이더를 피해 **이름표가 붙은 스테이지 고유 보물**을 훔칩니다.
4. 보물을 얻으면 녹슨 자물쇠 문이 초록색 `탈출!` 포털로 바뀝니다.
5. 스테이지 2부터는 8초가 끝나기 전에 `X`를 눌러 현재 동선을 **분신**으로 저장합니다.
6. 다음 루프에서 분신이 같은 이동과 `Z 미끼`를 반복합니다. 분신에게 발판과 유인을 맡기고 현재의 내가 탈출하면 됩니다.

첫 스테이지는 잠입을, 두 번째 스테이지는 이 게임의 핵심인 분신 협동을 가르칩니다.

## 핵심 규칙

```text
8초 동안 움직인다
        ↓
X로 이동과 행동을 분신에 저장한다
        ↓
분신과 동시에 움직여 보석을 훔치고 탈출한다
```

- `X`를 누르면 해당 루프의 이동 경로와 `Z 미끼` 사용 시점이 저장됩니다.
- 저장된 분신은 이후 루프마다 같은 행동을 동시에 반복합니다.
- 분신은 발판을 누르고, 경비를 유인하고, 문을 계속 열어 둘 수 있습니다.
- 발각·재시작·시간 종료는 분신을 자동으로 만들지 않습니다.
- 시간 종료 전에 `X`를 누르지 않은 현재 동선은 저장되지 않습니다.
- 발각되더라도 이미 저장한 분신은 유지됩니다.
- 후반 스테이지에서는 지정된 분신 수와 `Z 미끼` 역할도 충족해야 탈출할 수 있습니다.

## 조작법

### PC

| 조작 | 기능 |
|---|---|
| 방향키 / `WASD` | 이동 |
| 게임 화면 클릭 | 클릭한 위치로 자동 이동 |
| `Z` | 소리 미끼를 놓아 경비 유인 |
| `X` | 현재 동선과 행동을 분신으로 저장하고 처음으로 되감기 |
| `R` | 저장 없이 현재 루프 다시 시작 |
| `U` | 마지막 분신 취소 |
| `Backspace` | 현재 스테이지를 첫 루프부터 초기화 |
| `M` | 소리 켜기·끄기 |
| `Esc` | 스테이지 선택 화면 |

### 모바일

- 왼쪽 조이스틱: 이동
- `Z 미끼`: 경비 유인
- `X 분신`: 현재 행동 저장
- 하단 버튼: 다시 시작, 분신 취소, 스테이지 선택, 소리 설정

세로 화면에서는 플레이어 추적 카메라가 작동하고, 짧은 가로 화면에서는 게임과 조작기가 나란히 표시됩니다. 모든 주요 터치 영역은 최소 48px입니다.

## 화면에서 목표 읽기

| 표시 | 의미 |
|---|---|
| 빛나는 컷 보물과 이름표 | 반드시 훔쳐야 하는 스테이지 고유 보물. 가치가 최종 점수에 더해짐 |
| 녹슨 자물쇠와 `탈출구 잠김` | 보석을 얻기 전에는 나갈 수 없는 출구 |
| 초록 화살표 포털과 `탈출!` | 보석 획득 후 활성화된 최종 목적지 |
| `분신 발판 1/2` | 분신을 세워 연결된 문을 여는 바닥 스위치 |
| 빨간 부채꼴 | 경비의 실제 레이더 범위. 벽과 닫힌 문에서 정확히 잘림 |

레이더 그림과 실제 발각 판정은 같은 기하 데이터를 사용합니다. 벽 너머에 닿지 않은 레이더로는 잡히지 않습니다.

## 보물과 선택 아이템

각 스테이지의 고유 보물은 반드시 훔쳐야 하며, 보물 가치는 최종 점수에 자동으로 더해집니다.

| 단계 | 고유 보물 | 가치 |
|---:|---|---:|
| 1 | 태엽 다이아 | +300점 |
| 2 | 호박 기어 | +400점 |
| 3 | 캔디 루비 | +500점 |
| 4 | 구름 사파이어 | +600점 |
| 5 | 달빛 진주 | +700점 |
| 6 | 거울 오팔 | +800점 |
| 7 | 왕관 에메랄드 | +900점 |
| 8 | 자정 별보석 | +1,200점 |

선택 아이템은 현재 스테이지 도전 중 한 번만 획득할 수 있습니다.

- `시간 태엽`: 현재와 이후 루프의 제한시간 +1.5초, 수집 보너스 +150점
- `레이더 보호막`: 다음 레이더 노출 1회를 막고 수집 보너스 +250점. 경비와 직접 부딪히는 것은 막지 못함
- `보너스 조각`: 스테이지에 따라 +300·+400·+600·+800점

획득한 보물과 아이템은 발각·시간 종료·`R` 재시작·`X` 되감기 후에도 현재 스테이지 도전 동안 유지됩니다. `Backspace`로 스테이지 전체를 초기화하면 모두 사라집니다.

## 8개 스테이지

| 단계 | 장소 | 핵심 요소와 선택 아이템 | 경비 | 목표 분신 |
|---:|---|---|---:|---:|
| 1 | 태엽 박물관 | 기본 잠입 · 보너스 조각 +300 | 1 | 0 |
| 2 | 장난감 공장 | 미끼 분신 · 레이더 보호막 | 1 | 1 |
| 3 | 캔디 아케이드 | 발판과 문 · 시간 태엽 +1.5초 | 2 | 1 |
| 4 | 구름 연구실 | 두 발판과 회전 레이더 · 보너스 조각 +400 | 2 | 2 |
| 5 | 달빛 역 | 첫 추격자 · 시간 태엽 +1.5초 | 3 | 2 |
| 6 | 거울 성 | 두 문과 반대 회전 레이더 · 보호막 | 3 | 2 |
| 7 | 왕실 금고 | 세 분신 역할 분담 · 보너스 조각 +600 | 4 | 3 |
| 8 | 자정 시계탑 | 보스 작전 · 시간 태엽·보호막·보너스 조각 +800 | 4 | 3 |

경비는 느린 순찰형, 소리를 크게 듣는 청각형, 고정 렌즈, 회전 스캐너, 추격형, 엘리트와 보스로 점진적으로 확장됩니다.

각 스테이지는 서로 다른 장소색과 8초 칩튠을 사용합니다. BGM은 90 BPM에서 195 BPM까지 빨라지고, 정확히 8초마다 게임 루프와 함께 첫 박으로 돌아갑니다.

## 점수와 기기 랭킹

최종 점수는 **잠입 점수 + 필수 보물 가치 + 선택 아이템 보너스**입니다.

```text
잠입 점수
= max(0, 10,000
  - 레이더 노출 × 1,200
  - 재시도 × 650
  - 목표보다 많은 분신 × 250
  - 성공 루프의 5초 초과 시간 10ms당 1점)

최종 점수
= min(20,000, 잠입 점수 + 보물 가치 + 아이템 보너스)
```

| 항목 | 계산 |
|---|---:|
| 잠입 기본 점수 | 10,000점 |
| 레이더에 새로 노출된 구간 | 1회당 −1,200점 |
| 발각·시간 종료·`R` 재시작 | 1회당 −650점 |
| 스테이지 목표 수를 넘긴 분신 | 1개당 −250점 |
| 성공한 루프의 5초 초과 시간 | 1초당 −100점 |
| 필수 보물 | 스테이지에 따라 +300~+1,200점 |
| 시간 태엽 / 보호막 | 각각 +150점 / +250점 |
| 보너스 조각 | 스테이지에 따라 +300·+400·+600·+800점 |

수집 점수는 기록 경쟁의 총점에 반영하지만 실수를 가리지는 않습니다. 등급은 잠입 점수만으로 `S 9,000 이상`, `A 7,500 이상`, `B 6,000 이상`, 그 이하는 `C`입니다. 랭킹은 총점이 높은 순이며, 동점은 레이더 노출 → 재시도 → 분신 수 → 완료 시간이 적은 기록 순으로 정렬합니다.

프로필 이름·색상·표정을 설정할 수 있으며, 도전·클리어·발각·분신 통계와 스테이지별 상위 5개 기록을 확인할 수 있습니다.

현재 순위는 서버 순위가 아닌 **같은 브라우저·기기의 기록 비교**입니다. 브라우저 데이터를 삭제하면 기록도 초기화됩니다.

## Codex와 어떻게 만들었나요?

### 사람이 직접 결정한 부분

- “8초 전의 나와 협동하는 잠입 퍼즐”이라는 최종 게임 방향

- 경비 종류, 보스, 스테이지별 점진적 난이도와 점수 기준
- 모바일 조작, 다국어, 소리 자막과 실제 플레이 피드백
- 보석·녹슨 자물쇠·활성 출구처럼 즉시 읽히는 시각 언어

### Codex가 맡은 부분

- Canvas 2D 기반 코어 게임과 8초 행동 기록·재생 시스템 구현

- 경비 순찰·청각·회전·추격·보스 행동 구현
- 반응형 PC·모바일 UI와 터치 조작 구현
- 프로필·통계·점수·기기 랭킹 및 다국어 모듈 구현
- 캐릭터 원본 생성과 Agent Sprite Forge 후처리·QC
- 테스트 작성, 반복 QA, GitHub Pages 자동 배포

## 로컬 실행

Node.js 18 이상이 필요합니다. 별도 패키지 설치는 필요하지 않습니다.

```powershell
git clone https://github.com/sdj3261/openai_game_2026.git
cd openai_game_2026
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 기술 구성

| 영역 | 기술 |
|---|---|
| 게임 | Vanilla JavaScript ES Modules, Canvas 2D |
| 사운드 | Web Audio API로 합성한 스테이지별 8초 칩튠 |
| UI | HTML, CSS 디자인 토큰, 반응형 레이아웃 |
| 저장 | 브라우저 `localStorage` |
| 로컬 서버 | Node.js 내장 HTTP 서버 |
| 배포 | GitHub Actions, GitHub Pages |
| 테스트 | Node.js Test Runner, 정적 스모크 검사 |

## 시각 에셋과 라이선스

주인공과 최종 보스 원본은 이미지 생성으로 제작한 뒤 Agent Sprite Forge의 `generate2dsprite` 프로세서로 배경 제거, 프레임 분할, 정렬, 투명 PNG·GIF 내보내기와 QC를 수행했습니다.

원본 시트, 투명 시트, 개별 프레임, 사용 프롬프트와 검사 메타데이터를 `assets/sprites`에 함께 보관했습니다.

한글 게임 글꼴은 SIL Open Font License 1.1의 Galmuri11 Bold이며 [라이선스 원문](./assets/fonts/OFL-Galmuri.txt)을 포함합니다. 프로젝트 코드 자체에는 별도 라이선스가 부여되어 있지 않습니다.
