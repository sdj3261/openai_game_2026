# 게임 스프라이트 제작 기록

`duck-player/`와 `toy-guards/`는 이 프로젝트를 위해 새로 만든 오리지널 2D 게임 에셋입니다. 특정 상용 게임 캐릭터나 스프라이트를 복제하지 않았습니다.

- 원본 비주얼: Codex 내장 이미지 생성
- 후처리: Agent Sprite Forge `generate2dsprite.py`
- 배경 키: `#FF00FF`
- 출력: 투명 PNG 프레임, GIF 미리보기, `pipeline-meta.json`
- 검수: 빈 프레임·가장자리 접촉·붙여넣기 잘림·크기 편차·발 위치 편차 검사

## 캐릭터

- 주인공: 태엽 오리 도둑, 상·하·좌·우 4방향 × 4프레임
- 방해꾼: 몽둥이 순찰병, 호루라기 청음병, 장난감 궁수, 탐조등병, 그물총 추격병, 경비대장

각 폴더에는 재현 가능한 `prompt-used.txt`와 후처리/QC 기록인 `pipeline-meta.json`이 함께 들어 있습니다.
