# 《8초 도둑단》 최종 데모 대본

> 목표 영상 길이: 2분 40초~2분 59초
> 플레이: <https://sdj3261.github.io/openai_game_2026/>
> 구성: 최신 실제 게임 화면 + 한국어 내레이션 + 번인 자막 + 자체 생성 칩튠/SFX

## 1. 오프닝 훅 — 단 8초

- 당신에게 주어진 시간은 단 8초.
- 같은 8초 차례 안에 열쇠를 찾고, 열린 출구로 탈출하세요.
- 실패해도 괜찮습니다. 필요한 동선을 분신으로 남기면 됩니다.
- 8초가 쌓일수록 혼자였던 잠입은 진짜 팀플레이가 됩니다.

## 2. 게임 소개와 조작

- 8초 도둑단은 과거의 나와 협동하는 8초 잠입 게임입니다.
- 방향키나 모바일 조이스틱으로 움직이고, 제어는 두 버튼이면 충분합니다.
- Z는 현재 위치로 경비원을 도발해 불러오는 선택 기능입니다.
- X로 분신을 만들 수 있고, 탈출 조건은 열쇠 하나뿐입니다.

## 3. 핵심 기믹 — 분신 협동

- X를 누르면 지금까지 움직인 동선이 분신이 되고, 새로운 8초가 시작됩니다.
- 분신은 내가 했던 이동과 경비원 도발을 그대로 반복합니다.
- 분신이 발판을 누르는 동안, 현재의 나는 문을 지나 열쇠로 향합니다.
- 분신은 최대 10개이며 권장 수를 넘길수록 감점이 점점 커집니다.

## 4. 잠입 — 시야와 도발

- 경비원이 길을 막으면 Z로 현재 위치에 불러 시선을 돌릴 수 있습니다.
- 빨간 부채꼴에 몸이 정확히 닿을 때만 발각됩니다.
- 스테이지마다 경비와 문, 발판의 조합이 하나씩 늘어납니다.
- 시야는 벽에 가려지고, 보이는 영역과 실제 판정이 일치합니다.

## 5. 인간 경비의 무기

- 고정 궁수는 0.5초 주황 예고선 뒤 빠른 화살을 쏩니다.
- 화살은 낮은 포물선으로 날아와, 예고 방향에서 벗어나면 피할 수 있습니다.
- 그물총은 0.65초 청록 예고 뒤 더 느리고 더 높은 포물선으로 날아옵니다.
- 여러 프레임 간격에서도 같은 궤도와 충돌 결과인지 자동 테스트했습니다.

## 6. 최종 보스

- 여덟 번째 자정 시계탑에는 인간 경비대장이 기다립니다.
- 분신들의 동선을 겹쳐 발판을 열고, 현재의 나는 열쇠를 향합니다.
- 단순한 두 버튼이 마지막에는 정교한 협동 전략이 됩니다.
- 시간 태엽과 보호막, 별까지 챙기면 최종 점수를 높일 수 있습니다.

## 7. 점수와 랭킹

- 스테이지마다 다른 열쇠 점수와 보너스 아이템이 최종 점수에 더해집니다.
- 발각과 재시도가 적고, 분신을 알맞게 쓸수록 높은 등급을 받습니다.
- 권장 수를 한두 개 넘기면 작은 감점, 계속 늘리면 더 큰 감점이 붙습니다.
- 개인 기록과 스테이지별 기기 랭킹이 다시 도전할 이유를 만듭니다.

## 8. Codex 협업과 모바일

- Codex는 기획부터 구현, 스프라이트 제작과 테스트까지 함께했습니다.
- 사람은 재미의 규칙과 난이도를 결정하고, Codex는 빠르게 검증했습니다.
- 모바일 조작 영역은 화면 높이에 맞춰 움직이고, 이동 패드는 더 선명하게 보입니다.
- 설정에는 8초 규칙과 열쇠, 발판, 아이템 안내를 한눈에 담았습니다.
