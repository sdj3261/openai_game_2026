# 《8초 도둑단》 3분 데모 대본

> 목표 영상 길이: 2분 40초~2분 55초  
> 플레이: <https://sdj3261.github.io/openai_game_2026/>  
> 구성: 실제 게임 화면 + 한국어 내레이션 + 동기 자막 + 자체 생성 칩튠/SFX

## 1. 오프닝 훅 — 단 8초

- 당신에게 주어진 시간은 단 8초.
- 보석을 훔치고, 빨간 레이더를 피해 탈출하세요.
- 실패해도 괜찮습니다. 과거의 내가 다음 계획을 돕습니다.
- 8초가 쌓일수록 혼자였던 잠입은 진짜 팀플레이가 됩니다.

## 2. 게임 소개와 조작

- 8초 도둑단은 혼자 협동하는 타임루프 잠입 퍼즐입니다.
- 방향키나 화면 터치로 이동하고, 제어는 두 버튼이면 충분합니다.
- 시작 버튼을 누르면 설명보다 먼저 재미가 시작됩니다.
- 발각되거나 시간이 끝나도 자동 분신은 생기지 않아, 모든 선택이 내 것입니다.

## 3. 핵심 기믹 — 분신 협동

- 엑스를 누르면 방금 8초를 분신으로 저장하고 처음으로 돌아갑니다.
- 분신은 내가 했던 이동과 미끼를 그대로 반복합니다.
- 한 명은 발판을 누르고, 현재의 나는 열린 길로 빠져나갑니다.
- 필요한 만큼만 분신을 남기는 것이 퍼즐과 점수 모두의 핵심입니다.

> 실제 화면: 8초 종료 시 기록이 멈춘 채 보존되고, 모바일 X 버튼으로 분신을 저장한다. 분신은 색상과 번호로 구분된다.

## 4. 잠입 — 고정 궁수와 레이더

- 제트 키를 누르면 소리 미끼가 작동해 경비를 다른 방향으로 끌어냅니다.
- 빨간 부채꼴에 몸이 정확히 닿을 때만 발각됩니다.
- 스테이지마다 퍼즐 문법이 하나씩 더해집니다.
- 레이더는 벽에 가려지고, 보이는 영역과 실제 판정이 일치합니다.

## 5. 인간 경비의 무기

- 고정 궁수는 0.5초 주황 예고선 뒤 빠른 화살을 쏩니다.
- 화살은 낮은 포물선으로 날아와, 예고 방향에서 벗어나면 피할 수 있습니다.
- 그물총은 0.65초 청록 예고 뒤 더 느리고 더 높은 포물선으로 날아옵니다.
- 여러 프레임 간격에서도 같은 궤도와 충돌 결과인지 자동 테스트했습니다.

## 6. 최종 보스

- 여덟 번째 자정 시계탑에는 인간 경비대장이 기다립니다.
- 세 분신의 동선을 겹치고, 미끼 타이밍까지 맞춰야 합니다.
- 단순한 두 버튼이 마지막에는 정교한 협동 전략이 됩니다.
- 시간 태엽, 보호막, 보너스 조각까지 챙기면 최종 점수를 높일 수 있습니다.

## 7. 점수와 랭킹

- 필수 보물 가치와 보너스 조각이 잠입 점수에 더해집니다.
- 발각, 재시도, 불필요한 분신과 시간이 적을수록 높은 등급입니다.
- 개인 기록과 스테이지별 기기 랭킹으로 다시 도전할 이유가 생깁니다.
- 자정 별보석, 거울 오팔, 왕관 에메랄드처럼 스테이지마다 고유 보물이 있습니다.

## 8. Codex 협업

- Codex는 기획부터 구현, 스프라이트 제작과 테스트까지 함께했습니다.
- 사람은 재미의 규칙과 난이도를 결정하고, Codex는 빠르게 검증했습니다.
- 모바일, 다국어, 청각 접근성과 자동 시험도 실제 플레이로 확인했습니다.
- 반복한 플레이 피드백이 용어와 규칙, 충돌 판정을 지금 모습으로 다듬었습니다.
